# 3D Flip Card

A credit card that flips in 3D on hover, built with pure HTML and CSS.

**Live demo:** https://karbal-youssef.github.io/card-flip/

## Features
- 3D flip on hover (`perspective`, `preserve-3d`, `backface-visibility`)
- Glassmorphism effect (`backdrop-filter: blur`)
- Signature strip made with `repeating-linear-gradient`

## Run it
Download the files and open `index.html` in your browser.

## Note
All card data is fake.
